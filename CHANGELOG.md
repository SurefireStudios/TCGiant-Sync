# Changelog

Every release is documented in two places, and deliberately not a third:

- **[GitHub Releases](https://github.com/SurefireStudios/TCGiant-Sync/releases)** — the notes written for merchants at the time of each release. This is what the update checker uses, and it is the best place to read what changed and why.
- **[`changelog.txt`](changelog.txt)** — the plugin's own changelog, shipped inside every zip, with the same content in the format WordPress expects. `readme.txt` carries an abridged copy for the plugin directory.

This file exists so the repository has a changelog where people look for one. It is not a third copy that can drift from the other two.
