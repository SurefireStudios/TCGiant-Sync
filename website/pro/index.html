Questions sellers usually ask

Everything you need to know before getting started.

Does it work for eBay-first or WooCommerce-first setups?

Both. If you started on eBay, import your listings into WooCommerce. If you built your catalog in WooCommerce, push products to eBay. You can do both simultaneously — the plugin handles either direction.

How does Push to eBay work?

Open any WooCommerce product, go to the eBay Sync tab, and click Push to eBay. You can override the category and condition per-product. For bulk pushes, select products in your WooCommerce Products list and use the Bulk Actions dropdown.

What are eBay Business Policies and do I need them?

Business Policies are eBay's system for reusable Shipping, Return, and Payment settings across listings. They are required for the Push to eBay feature. Most seller accounts already have them enabled. If not, you can enroll at no cost directly on eBay.

What happens if a product already has an eBay listing?

TCGiant Sync automatically detects whether a product already has an eBay Item ID. If it does, the plugin updates the existing listing using ReviseItem instead of creating a duplicate.

Does it help prevent overselling?

Yes. Whenever something sells on eBay or WooCommerce, the plugin adjusts stock on the other platform automatically, preventing the same item from being sold twice.

How often does it sync?

You can set a schedule — every 15 minutes, hourly, twice daily, or daily. You can also trigger syncs manually at any time from the Import page.

Who is this plugin for?

Trading card sellers and collectibles dealers who sell on both eBay and their own WooCommerce site. It is built for fast-moving inventory with limited quantities where a single oversell can mean a refund and a negative review.
