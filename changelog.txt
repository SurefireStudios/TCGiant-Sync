*** TCGiant Sync Changelog ***

2026-06-29 - version 1.4.5
- Fix: Weight and dimensions are now correctly imported for non-US marketplaces (UK, CA, AU, DE, FR, IT, ES). Previously, metric values from eBay (e.g., 200g, 34cm) were incorrectly treated as imperial and double-converted (e.g., 200g became 5.67kg, 34cm became 86.36cm). The plugin now uses the configured marketplace to determine the source unit system when eBay doesn't include explicit unit metadata.
- Fix: Item Specifics (specs/attributes) now import correctly during delta syncs. The GetSellerEvents API call was missing the `IncludeItemSpecifics` flag, causing eBay to omit specs from the response.
- Fix: Product images now import reliably during delta syncs. If GetSellerEvents omits image or spec data for an item, the plugin automatically falls back to a GetItem call to fetch the full data.

2026-06-22 - version 1.4.4
- Feature: New "Add eBay Shipping Cost to Product Price" setting. When enabled, the flat-rate eBay shipping cost is automatically added to the WooCommerce product price on import (e.g., $10 item + $5 shipping = $15 in WooCommerce). Free shipping and calculated shipping items are unaffected. Defaults to off.

2026-06-22 - version 1.4.3
- Fix: Resolved category filter not matching any items during full sync. The eBay GetSellerList API was not returning Storefront (StoreCategoryID) and PrimaryCategory data because OutputSelector tags were overriding DetailLevel. Removed OutputSelector and switched to DetailLevel=ReturnAll to guarantee all item fields are returned.
- Fix: Improved import log clarity — page summaries now distinguish between total items scanned vs. items matched by the category filter (e.g., "Scanned 100 items, 3 matched" instead of "Scanned 100 items matching NBA").
- UX: Added a contextual settings bar on the Import page showing active category filter, auto-sync interval, and data mapping overwrite settings at a glance, with a direct link to edit settings.
- UX: Dashboard "Recent Activity" log now renders at full width instead of being confined to the left column of the 2-column grid.

2026-06-18 - version 1.4.2
- Performance: Initial full imports now process simple products inline from enriched GetSellerList data, eliminating per-item GetItem calls for non-variation products. A 15,000-item store with 5% variations drops from ~15,150 API calls to ~900 calls (~94% reduction).
- Improvement: GetSellerList now requests full item data (Description, SKU, Prices, PictureDetails, ItemSpecifics, ShippingPackageDetails) via expanded OutputSelectors and IncludeItemSpecifics.
- Improvement: Variation products are automatically detected and routed to the proven GetItem fallback path for reliable full data retrieval.
- Improvement: Image downloads for inline-processed items are now scheduled as separate async jobs to prevent page processing timeouts.
- Improvement: Activity log now shows "[inline]" tag for products imported directly from GetSellerList data, and reports both inline and GetItem counts per page.

2026-06-18 - version 1.4.1
- Performance: Delta syncs now use eBay's GetSellerEvents API with DetailLevel=ReturnAll, returning full item data inline. This eliminates all per-item GetItem API calls during scheduled syncs. A 15,000-item store on hourly sync now uses ~24-72 API calls/day instead of ~1,200-4,800.
- Improvement: GetSellerEvents returns complete item data (Description, ItemSpecifics, Variations, PictureDetails, ShippingPackageDetails) in a single API call per sync cycle.
- Improvement: Automatic fallback to GetItem for individual items if critical data (Title, SellingStatus, Variations) is missing from the events response.
- Improvement: 48-hour window auto-chunking for stores that haven't synced in days. Each sync processes up to 48hrs of changes, with subsequent syncs continuing from where it left off.
- Note: Full imports (manual "Fetch Inventory" button) are unchanged and still use the proven GetSellerList + GetItem flow.

2026-06-18 - version 1.4.0
- Performance: Implemented Delta Sync for scheduled imports. Cron-triggered syncs now only fetch eBay listings modified since the last successful sync, dramatically reducing API usage. A 10,000-item store on hourly sync drops from ~242,000 API calls/day to ~1,200-4,800/day.
- Improvement: GetSellerList API call now supports ModTimeFrom/ModTimeTo filtering for delta mode, while maintaining full EndTimeFrom/EndTimeTo scan for manual imports.
- Improvement: Sync state now tracks sync_mode (full/delta), delta_mod_from timestamp, and last_successful_sync_at for reliable delta cycling.
- Improvement: Delta sync includes a 5-minute overlap buffer to prevent missed items due to clock skew between WordPress and eBay servers.
- Improvement: Activity log now shows [delta] tag on scan entries during delta sync mode for easy identification.
- Note: Manual "Fetch Inventory" button continues to trigger a full sync. Delta sync is used exclusively for automated scheduled syncs.

2026-06-16 - version 1.3.1
- Security: Replaced the hardcoded webhook signing key with a unique, cryptographically random per-installation key. Each site now receives its own signing key from the relay server during OAuth connection, preventing forged Marketplace Account Deletion requests.
- Improvement: Legacy installations that haven't reconnected will continue to work using the previous key until they re-authenticate.

2026-06-16 - version 1.3.0
- Feature: Import product weight and package dimensions (length, width, height) from eBay listings into WooCommerce. Values are automatically converted to match your store's configured weight and dimension units.
- Feature: Added "Overwrite Weight & Dimensions" toggle in the Data Mapping settings section, allowing users to control whether weight/dimensions are updated on re-imports (defaults to Yes).
- Improvement: Import activity log now shows imported weight alongside existing product details (e.g., "0.50lbs") for verification.

2026-06-09 - version 1.2.3
- Fix: eBay Item Specifics (specs) are now correctly saved as WooCommerce Product Attributes. Fixed a WooCommerce compatibility issue where custom attributes were silently discarded due to missing position and ID metadata.
- Fix: Import now survives eBay API rate limits. When the daily API call limit is reached during a large import (6,000+ items), the sync automatically pauses and schedules a retry in 5 minutes instead of restarting from scratch. A new "Resume Import" button is also available for manual recovery.
- Feature: Added `rate_limited` sync state with visual indicator (amber pulsing dot), progress preservation, and auto-retry scheduling.
- Improvement: Import log now shows the number of attributes detected per product (e.g., "8 attrs") to help verify spec extraction.
